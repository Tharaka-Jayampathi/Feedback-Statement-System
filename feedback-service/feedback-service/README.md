# 💬 Feedback Service (Spring Boot Microservice)

This is the Spring Boot backend microservice for the **Feedback Statement & Sentiment Analysis System**.

Please refer to the [Root README.md](../../README.md) for full project architecture, database setup, Python AI microservice integration, and API documentation.

### Quick Run
```powershell
.\mvnw.cmd spring-boot:run
```
*(Requires MySQL running with `feedback_db` and Python AI microservice running on port 8000)*
